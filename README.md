# To-Do List Manager

A simple Python application to manage tasks using core Python.

## Features

- Add new tasks
- Remove tasks
- Show task list
- Save tasks to JSON file

## Setup

1. Ensure Python 3.8+ is installed.
2. Clone this project.
3. Run `python main.py` from the project root.

## Folder Structure

- `src/`: Core logic (Task, TaskManager, Storage classes).
- `data/`: Stores tasks.json.
- `main.py`: Entry point.

## Example

```
To-Do List Manager
1. Add Task
2. Remove Task
3. Show Tasks
4. Exit
Enter choice (1-4): 1
Enter task name: Learn Python
Task added!
```
